# Lessons

Each lesson gets its own folder (`01-setup/`, `02-first-agent/`, …) with a README that covers:

1. **The idea**: what it is, in one line, with a .NET comparison
2. **Code to paste**: each block names the file it belongs in
3. **Commands to run**: one per block, each with what it does
4. **What to look for**: in the terminal and in the Cloud console
5. **Check yourself**: two or three questions

The plan is in [`../docs/lesson-plan.md`](../docs/lesson-plan.md). Lesson 0 is [`../index.html`](../index.html).
